# TACAS

[← All docs](index.md)

TACAS is a shared tactical situation map with an imagery basemap, labeled geographic markers, and a text channel for TACAS positions.

Sign-in defaults to the **JTAC** position. Enter a callsign for either position type. JTAC positions are identified as `<callsign> JTAC` and do not display aircraft, even when the callsign matches a live aircraft. Select **Aircrew** to sign in with an aircraft callsign; that distinct position is shown on the controller list and, when its callsign matches a live airborne aircraft, the scope centers on and displays the aircraft with its type appended to the callsign. TACAS positions do not use radio frequencies.


## Satellite map

The map opens around the mission bullseye, or around live units when a bullseye is unavailable. Drag to pan, use the wheel or +/− controls to zoom, and select the center control to recenter on live units. Toggle **MGRS** in the map toolbar to show the grid overlay. Up to zoom 6 it shows grid-zone-designator squares; at zooms 7–9 it adds 100,000m square identifiers, and from zoom 10 onward it adds one level of grid precision per zoom step, down to 1m spacing.

The map uses the custom DCS Olympus imagery tileset for supported mission theatres (Caucasus, Germany, Mariana Islands, Mariana Islands WWII, Nevada, Normandy, Persian Gulf, and Syria). Esri World Imagery is used for other theatres and rendered beneath custom tiles, filling areas where custom imagery has no tile coverage. Both sources require internet access; see [Third-party notices](../THIRD_PARTY_NOTICES.md).

## Markers

Enter a label and select **＋ Marker**, then click the map to place it. JTAC positions can also place an **Echo Point**, a distinct CAS reference point; each JTAC can have one, and placing another replaces that JTAC's previous Echo Point without affecting other JTACs' points or shared bullseyes. Echo Points appear on the map but are not included in the regular markers list. Use **HIDE ALL/SHOW ALL** in the **MARKERS** panel to toggle regular marker visibility, or the separate **HIDE ALL/SHOW ALL** control in the **ECHO POINTS** panel to toggle Echo Point visibility. Per-item **HIDE/SHOW** controls in both lists toggle individual points. These visibility settings are local to your device, are remembered there, and do not remove points or affect other users; hiding an Echo Point also hides its cardinal lines. Any TACAS controller, including Aircrew, can choose an Echo Point in the **ECHO POINTS** panel to use as their local cursor-readout origin; this does not change the point's owner or affect anyone else's selection. Each sign-in starts with the JTAC's own Echo Point selected, if available, or no selection for other positions. The cursor readout shows bearing and range from the selected Echo Point; within 10° of a cardinal direction it uses the Echo Point line letter and distance (for example, **A10 NM**), otherwise it shows numeric bearing and range. Range units follow the **FT/M** elevation setting: feet uses NM and meters uses KM. Without a selected Echo Point, the cursor readout shows coordinates. By default, each Echo Point draws four dashed cardinal lines to the map edges, labeled **A** (north), **B** (east), **C** (south), and **D** (west). Use the **ECHO ON/OFF** control to show or hide these lines and labels locally; this preference is remembered on the device and does not affect other users. Echo Points themselves are visible to TACAS users only, like regular markers. All active TACAS positions receive point additions and removals, and a newly joined position receives the current point set from an existing TACAS peer. Use the coordinate-format control in the map toolbar to cycle DMS, decimal degrees, MGRS, DDM (degrees and decimal minutes), and theatre-specific absolute metric X/Y coordinates for the cursor readout, point coordinates, and 9-line Line 6. The selection is remembered on this device. Metric X/Y is available when the current theatre has a defined projection. Use the **FT/M** control to switch terrain elevation labels and the 9-line Line 4 between feet and meters; that selection is also remembered on the device. Select a marker in the list to center the map on it; **9-line** opens a CAS 9-line draft with the marker coordinates in Line 6 and terrain elevation in Line 4, when elevation data is available. Edit the fields and send the brief to TACAS chat, or close the builder to discard it. × removes a marker for everyone in TACAS.

## TACAS chat

The TACAS chat is separate from the general Messages window. It is received only by positions signed into TACAS, and a newly joined TACAS position receives the recent conversation while a peer remains connected.
The chat heading shows the DCS mission clock, defaulting to Zulu (`Z`); select the clock to switch between Zulu and theatre-local (`L`) time. Message and Aircrew check-in update timestamps use DCS mission time and follow the selected Zulu/local format.

Aircrew can select **CHECK-IN** above the map to submit an eight-line check-in: Identification/Mission Number, Number and Type of Aircraft, Position and Altitude, Ordnance, Playtime, Capabilities, Abort Code, and Remarks. Each Aircrew callsign has one current check-in; submitting another replaces it. All current check-ins appear in the **AIRCREW CHECK-INS** section of the right panel. Select a check-in to open its full details.
